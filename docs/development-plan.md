# План разработки с использованием AI

AI использовался как помощник для декомпозиции задачи, поиска edge cases и
черновиков кода. Архитектурные решения и итоговый код проверяются автором.

1. Выделить домены: каталог, меню, заказ, интеграция заведения; зафиксировать
   явную модель статусов и границы MVP.
2. Описать API сначала в OpenAPI и CJM, затем подобрать таблицы и миграцию.
3. Реализовать Core с транзакционным резервом остатков и snapshots цены.
4. Сделать отдельный сервис одного заведения, который использует только
   опубликованный API Core: webhook для быстрого уведомления и pull API как
   запасной канал.
5. Добавить Docker Compose, линтер, контрактные тесты и ручной demo-сценарий.
6. Перед сдачей запустить `docker compose up --build`, пройти happy path,
   отказ заведения, нулевой остаток и отмену до принятия.
